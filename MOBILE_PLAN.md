# MMD Studio — Mobile Plan

Goal: first-class phone (portrait + landscape) and tablet support without changing the desktop layout.
Baseline screenshots (before any change): `docs/mobile/baseline/{390x844,844x390,768x1024,1024x768,1440x900}.png`.

## Audit: desktop-only assumptions → fix

| #   | Assumption (where)                                                                  | Problem on mobile                                                 | Fix                                                                                                                                                                                                                |
| --- | ----------------------------------------------------------------------------------- | ----------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 1   | Fixed 3-column `react-resizable-panels` layout (`App.tsx`)                          | Unusable < 640 px; panels squashed                                | `useBreakpoint()` + `layoutMode` slice; phone = full viewport + bottom sheets + tab bar; phone-landscape = viewport + right side panel; tablet = viewport + overlay drawers + bottom timeline; desktop = unchanged |
| 2   | Engine owned by `Viewport` component                                                | Switching layouts (rotation) would remount → engine/project reset | Engine + canvas created once in `engineHost.ts`; `Viewport` only re-parents the persistent canvas                                                                                                                  |
| 3   | `MobileNotice` banner                                                               | Spec now requires real support                                    | Removed                                                                                                                                                                                                            |
| 4   | `html,body{height:100%}`, no safe areas                                             | iOS URL bar / notch / home indicator overlap                      | `100dvh`, `viewport-fit=cover`, `env(safe-area-inset-*)` paddings on shell, tab bar, sheets                                                                                                                        |
| 5   | Drag & drop as primary import (`Viewport`)                                          | No DnD on phones                                                  | Prominent Add model / motion / audio / ZIP / project buttons (empty state, Models panel); ZIP recommended                                                                                                          |
| 6   | `webkitdirectory` folder picker                                                     | Not on iOS/Android                                                | Hidden on touch devices; ZIP path documented                                                                                                                                                                       |
| 7   | `accept` lists (`filePickers.ts`)                                                   | iOS greys out `.pmx/.vmd`                                         | Per-purpose accept lists; none on iOS for MMD types; MIME (`audio/*`, `application/zip`) where reliable                                                                                                            |
| 8   | Hover-only affordances: Radix tooltips, `group-hover` action reveal (`ModelsPanel`) | Invisible on touch                                                | Long-press shows the label; actions always visible on coarse pointers                                                                                                                                              |
| 9   | Small hit targets (24–28 px icon buttons, 12 px slider thumbs, 16 px switches)      | Below 44 px guideline                                             | `coarse:` Tailwind variant → 44 px buttons, 28 px thumbs, larger switches & rows                                                                                                                                   |
| 10  | Sliders only (`SliderRow`, morphs)                                                  | Hard to set precise values by finger                              | Coarse pointers get −/+ steppers with long-press auto-repeat (fine adjustment)                                                                                                                                     |
| 11  | Keyboard-only shortcuts (`useShortcuts`)                                            | No keyboard on phones                                             | On-screen: frame step, undo/redo, loop, focus, gizmo mode buttons in transport/tool bars                                                                                                                           |
| 12  | Mouse-oriented viewport (`ArcRotateCamera` defaults)                                | Pinch/pan feel wrong; page scroll/zoom steals gestures            | `touch-action:none`, `overscroll-behavior:none`; tuned pinch/pan; double-tap focus; tap to pick model/bone                                                                                                         |
| 13  | Gizmo sized for mouse                                                               | Hard to grab                                                      | Larger `scaleRatio` on coarse pointers; on-screen rotate/move/scale toggles                                                                                                                                        |
| 14  | Timeline: wheel zoom, thin playhead (`Timeline.tsx`)                                | No wheel on touch                                                 | Two-finger pinch zoom + pan, large playhead handle, touch scrubbing                                                                                                                                                |
| 15  | Playback updates through store at ~15 Hz                                            | Re-renders on low-end phones                                      | Time display/timeline via refs + rAF; store gets state changes and throttled frames                                                                                                                                |
| 16  | Quality defaults (Medium, MSAA 4, DPR up to 1.5–device)                             | Too heavy for phones                                              | Mobile defaults to Low (DPR cap 1.5, MSAA off, FXAA on, 1024 shadows, 3 substeps); DPR cap 2 otherwise; Adaptive quality controller                                                                                |
| 17  | Render loop always on                                                               | Wastes battery when hidden or covered by a full sheet             | Pause when tab hidden or full sheet covers the viewport (unless playing)                                                                                                                                           |
| 18  | No memory guards                                                                    | Big PMX/4K textures crash mobile tabs                             | Warn for PMX > 30 MB on low-memory devices; downscale textures (2048 cap, 1024 on Low); context-lost/restore handling + recovery toast                                                                             |
| 19  | Monaco Playground                                                                   | Poor on phones; heavy                                             | Phones get a read-only example runner (no Monaco); editor stays on tablet/desktop                                                                                                                                  |
| 20  | Audio starts from first `play()`                                                    | iOS requires a gesture to unlock `AudioContext`                   | Unlock on first pointer/touch gesture                                                                                                                                                                              |
| 21  | Video export assumes MediaRecorder/WebCodecs                                        | iOS Safari limits codecs                                          | Capability detection, clear message, PNG-sequence ZIP fallback (frame-stepped)                                                                                                                                     |
| 22  | Downloads via `<a download>`                                                        | Awkward on iOS                                                    | `navigator.share({files})` when available on touch devices                                                                                                                                                         |
| 23  | Not installable                                                                     | —                                                                 | PWA: manifest, icons, service worker (app shell + Bullet WASM precache, never user blobs), Web Share Target (Android), install hint in More                                                                        |
| 24  | Contrast of `fg-dim` (#6b7285 on #0f1115 ≈ 3.9:1)                                   | Fails AA for small text                                           | Raise to ≥ 4.5:1                                                                                                                                                                                                   |
| 25  | Animations                                                                          | Motion sensitivity                                                | `prefers-reduced-motion` disables sheet/transition animations                                                                                                                                                      |

## Layout modes (`computeLayoutMode`)

- `phone` — width < 640 (portrait-ish)
- `phone-landscape` — height < 500 and width < 1024 (landscape phones)
- `tablet` — 640 ≤ width ≤ 1024
- `desktop` — width > 1024
